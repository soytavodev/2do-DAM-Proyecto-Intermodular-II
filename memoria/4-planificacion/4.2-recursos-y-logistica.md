# 4.2. Recursos y logística necesaria para cada tarea

Para cada grupo de tareas, esto es lo que tengo que tener preparado antes de empezar:

- Preparación (T1 a T5): computadora con Android Studio y el plugin de Kotlin Multiplatform actualizados, cuenta de GitHub, celular Android con la depuración por USB activada y un cable USB, MySQL instalado en local y un correo para registrarme en alwaysdata y Brevo.
- Contenido (T6 a T9 y T29 a T31): la plantilla JSON de una unidad, el temario del apartado 3.4, los descriptores de A1 y A2 del MCER, acceso a Tatoeba y Wikimedia Commons para frases e imágenes, el registro de licencias y la lista de revisión de cada unidad.
- Base de la app y lógica (T10 a T21): el contenido de al menos la unidad 1, Android Studio, el emulador y el celular de pruebas, y la documentación de Compose Multiplatform y de TextToSpeech.
- Servidor (T22 a T26): PHP y MySQL en local, una herramienta para probar la API (por ejemplo, la extensión REST Client de Visual Studio Code o curl), las credenciales de alwaysdata y la clave de la API de Brevo guardadas fuera del código.
- Cuentas y sincronización (T27 y T28): la API publicada y un correo real para recibir los códigos de prueba.
- Versión web (T32 a T34): navegadores Chrome, Firefox y Edge en la computadora, Safari en el iPhone, y un lugar donde publicar la web.
- Pruebas con usuarios (T36): al menos 5 personas, un guion con las tareas que van a hacer, el cuestionario y un celular o computadora para que prueben si no usan el suyo.
- Cierre (T38 a T40): la clave para firmar el APK, guardada en un lugar seguro y con copia, y la memoria al día.

En cuanto a logística, todo el trabajo lo hago en mi casa, con mi computadora y mis dispositivos. Las pruebas con usuarios las puedo hacer en persona o a distancia, enviando el enlace de la web o el APK.
