# 3.6. Recursos materiales y personales necesarios

RECURSOS MATERIALES Y TÉCNICOS

Hardware:
- Computadora portátil Acer Nitro 5 con procesador AMD Ryzen 7 de la serie 6000, 32 GB de RAM, dos discos SSD de 1 TB y tarjeta gráfica NVIDIA GeForce RTX 3070 Ti. Es mi equipo personal y tiene potencia de sobra para Android Studio y el emulador.
- Un celular Android para probar la app en un dispositivo real.
- Un iPhone 11, para probar la versión web en Safari.

Sistema operativo y software, todo gratuito:
- Ubuntu como sistema de desarrollo.
- Android Studio con el plugin de Kotlin Multiplatform, para la app de Android y la web.
- Visual Studio Code, para el código PHP y los archivos de contenido.
- PHP y MySQL en local, para desarrollar y probar la API.
- Git y GitHub, para el control de versiones y las copias del código.
- Navegadores Chrome, Firefox y Edge, y Safari en el iPhone, para probar la web.

Librerías y tecnologías: Kotlin, Kotlin Multiplatform, Compose Multiplatform, Ktor Client para la conexión con la API, y PHP con PDO para el servidor. Todas son de código abierto y gratuitas.

Servicios externos:
- alwaysdata, plan gratuito: alojamiento de la API, de la base de datos MariaDB (MySQL) y, si conviene, de la versión web.
- Brevo, plan gratuito: envío de los correos con el código de acceso.
- GitHub: repositorio del código.
- Opcional: cuenta de desarrollador de Google Play, para publicar la app.

Contenido:
- Imágenes propias o con licencias libres compatibles.
- Frases de ejemplo de Tatoeba, con licencia CC BY 2.0 FR, cuando hagan falta.
- La voz sintética de cada dispositivo para el audio.


RECURSOS PERSONALES

El proyecto lo hago solo, así que cumplo todos los papeles. Pero si Freenglish se hiciera en una empresa, harían falta estos perfiles:

- Jefe de proyecto: planifica, coordina y controla los plazos y el alcance.
- Especialista en enseñanza de inglés: diseña el temario por niveles del MCER y define cómo se evalúa.
- Redactor de contenido y revisor nativo de inglés: escribe las unidades y comprueba que el inglés sea correcto y natural.
- Diseñador de experiencia e interfaz (UX/UI): diseña las pantallas y cuida la accesibilidad.
- Desarrollador de aplicaciones multiplataforma: programa la app de Android y la web con Kotlin y Compose.
- Desarrollador backend: programa la API en PHP y diseña la base de datos.
- Técnico de pruebas (QA): prepara y hace las pruebas y organiza las pruebas con usuarios.
- Técnico de sistemas: publica la API y la web, y se ocupa de la seguridad y de las copias de seguridad.
- Asesoría legal, de forma puntual: revisa la protección de datos y las licencias.

En un equipo pequeño, varios de estos papeles los podría hacer la misma persona. Por ejemplo, el desarrollador multiplataforma podría hacer también el backend, y el jefe de proyecto podría encargarse de las pruebas con usuarios. Las horas de cada perfil y su costo los calculo en los apartados 4.6 y 4.7.
