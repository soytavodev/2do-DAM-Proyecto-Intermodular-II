# 3.7. Necesidades de financiación

PONER EN MARCHA EL PROYECTO

Freenglish no necesita financiación externa para hacerse como proyecto de clase. El costo directo es de 0 €, porque:

- La computadora y los celulares de prueba ya los tengo.
- Todo el software que uso es gratuito: Android Studio, Visual Studio Code, PHP, MySQL, Git y las librerías de Kotlin.
- El alojamiento de la API y de la base de datos es el plan gratuito de alwaysdata, que según su web es gratis de por vida.
- El envío de correos es el plan gratuito de Brevo, con 300 correos al día.
- No necesito un dominio propio, porque el alojamiento ya da una dirección con HTTPS.
- El contenido lo hago yo, y las imágenes son propias o con licencias libres.

Esto no quiere decir que el proyecto no tenga valor económico: si lo hiciera una empresa, habría que pagar las horas de trabajo y la parte proporcional de los equipos. Ese cálculo lo hago en la valoración económica (apartado 4.7).


COSTOS OPCIONALES

- Publicar en Google Play: un pago único de 25 dólares por la cuenta de desarrollador. Solo si decido publicarla; si no, la app se entrega como APK.
- Dominio propio, como freenglish.app o similar: tiene un costo anual, pero no es necesario.


SI EL PROYECTO CRECE

Si Freenglish llegara a tener muchos usuarios, los planes gratuitos se quedarían cortos y habría costos mensuales:

- Alojamiento: el siguiente plan de alwaysdata, Plus, empieza en 5 € al mes más IVA, según su web.
- Correos: si se superaran los 300 correos al día, habría que pasar a un plan de pago de Brevo o a otro servicio.

Para cubrir esos costos sin publicidad ni funciones de pago, las opciones serían las donaciones y los fondos para proyectos de código abierto que vi en el apartado 2.8, idealmente a través de una asociación sin fines de lucro (apartado 2.7).


CONCLUSIÓN

El proyecto no necesita financiación externa para ponerse en marcha, porque todo lo necesario es gratuito o ya lo tengo. Solo habría gastos si se publica en Google Play (25 dólares, una vez) o si el número de usuarios obliga a cambiar de plan.
