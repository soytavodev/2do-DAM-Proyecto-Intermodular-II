# 3.5. Actividades necesarias para el desarrollo

Además de programar, hay actividades de preparación sin las que no podría empezar o terminar el proyecto. Estas son las que necesito:

1. Preparar el equipo. Actualizar Android Studio, instalar el plugin de Kotlin Multiplatform y comprobar que el emulador de Android funciona bien con la tarjeta gráfica.

2. Preparar el celular de pruebas. Activar las opciones de desarrollador y la depuración por USB en el celular Android, y comprobar que Android Studio lo reconoce.

3. Crear los repositorios. Un repositorio en GitHub para el código de la app y del servidor, separado del repositorio de la memoria, con su archivo .gitignore para no subir claves ni archivos generados.

4. Elegir las licencias. Decidir la licencia de código abierto del código y confirmar la licencia CC BY-SA del contenido, y dejarlas escritas en el repositorio.

5. Crear las cuentas de los servicios externos. Una cuenta en alwaysdata para la API y la base de datos, y una en Brevo para enviar los correos. Las claves de estos servicios se guardan fuera del código.

6. Preparar el entorno del servidor en local. Crear la base de datos de desarrollo en MySQL con un usuario propio para el proyecto, sin usar root.

7. Preparar la plantilla del contenido. Definir el formato JSON de una unidad y escribir la unidad 1 completa como modelo para las demás.

8. Conseguir las imágenes. Buscar o crear imágenes con licencias compatibles y anotar en un registro el origen, el autor y la licencia de cada una.

9. Preparar la política de privacidad. Redactar un texto sencillo con los datos que se guardan, para qué y cómo borrarlos.

10. Preparar las pruebas con usuarios. Buscar al menos 5 personas dispuestas a probar la app, preparar las tareas que van a hacer y un cuestionario corto.

11. Si se publica en Google Play: crear la cuenta de desarrollador, preparar los textos e imágenes de la ficha de la app y llenar la sección de seguridad de los datos.

No necesito contratar un servidor de pago ni registrar un dominio: el alojamiento gratuito ya da una dirección propia con HTTPS.
