# 2.8. Posibles ayudas o subvenciones para la incorporación de nuevas tecnologías

Busqué ayudas públicas y privadas que podrían servir para un proyecto como Freenglish. La conclusión es que, hoy, ninguna encaja del todo, pero hay algunas opciones a tener en cuenta si el proyecto crece. Consulté todo el 15 de noviembre de 2026.


KIT DIGITAL

Es el programa del Gobierno para ayudar a pymes y autónomos a digitalizarse, con bonos para pagar servicios como una web o herramientas de gestión. No me sirve por dos razones: está pensado para empresas que contratan esos servicios a un agente digitalizador, no para desarrollar un producto propio, y según la web oficial España Digital el plazo de las últimas convocatorias abiertas terminó a finales de octubre de 2025.


AYUDAS AL EMPRENDIMIENTO EN LA COMUNITAT VALENCIANA

Encontré programas de Labora y del IVACE, pero la mayoría son ayudas para que las empresas contraten a jóvenes o itinerarios de formación para emprender, como Labora Emprén. No encontré ninguna subvención para una persona que quiera crear una app educativa gratuita. Si en el futuro Freenglish pasa a ser una asociación sin fines de lucro, estos programas de formación me podrían servir para organizarla bien.


FONDOS PARA SOFTWARE DE CÓDIGO ABIERTO

Esta es la opción que más encaja con Freenglish. La fundación neerlandesa NLnet reparte, con dinero de la Unión Europea (programa NGI Zero), ayudas de entre 5.000 y 50.000 euros para proyectos de código abierto. Su fondo NGI Zero Commons cerró su última convocatoria el 1 de junio de 2026, pero en su web siguen apareciendo otros programas abiertos, como Open Internet Stack. Es un camino a vigilar, aunque sus convocatorias están pensadas sobre todo para tecnología de internet, así que habría que ver si un proyecto educativo encaja.


DONACIONES

Como pasa con VLC o Khan Academy (apartado 2.4), lo más realista para mantener Freenglish a largo plazo son las donaciones voluntarias de los usuarios y de quien quiera apoyar el proyecto, a través de plataformas como GitHub Sponsors u Open Collective. Para recibirlas de forma ordenada, lo mejor sería crear una asociación sin fines de lucro (apartado 2.7).


CONCLUSIÓN

Para el proyecto de clase no necesito ninguna ayuda, porque el presupuesto es de 0 € (apartado 3.7). Si Freenglish sigue adelante después, las opciones más realistas son los fondos para código abierto y las donaciones, siempre sin agregar publicidad ni funciones de pago.
