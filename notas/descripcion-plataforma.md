# Descripción para «Datos del proyecto» (versión del 23/11/2026)

Nombre: Freenglish

Descripción:
Aplicación multiplataforma (Android y web), completamente gratuita y de código abierto, para que personas hispanohablantes aprendan inglés desde cero hasta el nivel A2 del Marco Común Europeo de Referencia. Une el aprendizaje por contexto (imagen, texto y audio) con unidades ordenadas y la gramática explicada en español. El alumno solo avanza cuando aprueba la prueba de cada unidad, lo que falla vuelve a aparecer mezclado con lo nuevo, el vocabulario se repasa con repetición espaciada, hay una prueba de nivel al empezar y cada error se explica. Se puede probar sin registrarse, y con una cuenta (solo correo y nombre de usuario) el progreso se guarda y se sincroniza entre dispositivos. Está hecha con Kotlin Multiplatform y Compose Multiplatform, con una API en PHP y base de datos MySQL, y funciona con servicios gratuitos para que mantenerla cueste 0 € al mes.
