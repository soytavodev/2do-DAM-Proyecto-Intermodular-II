# Freenglish · memoria del Proyecto Intermodular II

**Free Languages for everybody**

Memoria del proyecto final del ciclo de Desarrollo de Aplicaciones Multiplataforma (2.º DAM, CEAC FP, curso 2026-2027), realizada por Gustavo Delnardo.

Freenglish es una aplicación web y móvil, gratuita y de código abierto, para que personas hispanohablantes aprendan inglés desde cero hasta el nivel A2 del Marco Común Europeo de Referencia.

## Estructura

- `memoria/`: un archivo por apartado, en el orden de la guía de la memoria.
- `notas/`: investigación y notas de trabajo.

El código de la aplicación estará en su propio repositorio.
